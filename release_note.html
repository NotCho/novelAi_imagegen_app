NAIApp 1.5.3 업데이트 소식

1.4.0 이후 적용된 기능 개선과 로그인 핫픽스를 모아 정리했습니다. 로그인은 Persistent API Token 전용으로 변경됩니다.

[중요] 로그인 방식 변경 안내

NovelAI의 기존 로그인 API에 reCAPTCHA 인증이 추가되면서, 앱에서 이메일과 비밀번호로 로그인하던 방식은 더 이상 안정적으로 사용할 수 없게 되었습니다. 현재 NAIApp에서 기존 로그인 형태를 계속 지원하는 것은 사실상 불가능한 상황입니다.

이에 따라 NAIApp은 NovelAI 웹에서 직접 발급한 Persistent API Token 로그인만 지원합니다. 사용자 대상 서드파티 앱은 Persistent API Token을 사용해야 한다는 NovelAI의 권고사항도 함께 반영한 변경입니다.

1.5.3 핫픽스: NovelAI의 이미지 API 주소 변경으로 Persistent Token 확인이 실패하던 문제를 수정했습니다. 토큰 로그인 시 Please refresh NovelAI.net 오류가 표시됐다면 1.5.3으로 업데이트해 주세요.

모델 선택 UI: 모델명 앞 아이콘을 제거하고 긴 모델명도 두 줄까지 표시되도록 개선했습니다.

  1. NovelAI 웹사이트에 로그인한 뒤, 좌측 상단 설정(톱니바퀴)의 Account 메뉴로 이동합니다.
  2. Persistent API Token 발급 메뉴에서 토큰을 생성하고 복사합니다.
  3. NAIApp 로그인 화면에 토큰을 붙여넣어 로그인합니다.

주의: NovelAI에서 Overwrite로 새 토큰을 발급하면 기존 토큰이 무효화될 수 있습니다. 다른 앱에서 같은 토큰을 사용 중이라면 새 토큰으로 다시 등록해 주세요.

[캐릭터 프롬프트] 필요한 프롬프트만 사용

  • 추가한 캐릭터 프롬프트를 개별적으로 ON/OFF할 수 있습니다.
  • OFF 상태인 캐릭터 프롬프트는 이미지 생성 요청에서 제외됩니다.
  • 목록에서 비활성화된 캐릭터 프롬프트를 더 쉽게 구분할 수 있습니다.

[편의 기능] 시드 표시 설정

  • 자동 생성 버튼 패널에서 생성 이미지의 시드 표시 여부를 선택할 수 있습니다.
  • 선택한 시드 숨김/표시 상태는 앱을 다시 실행해도 유지됩니다.

[디자인] Liquid Glass 효과와 화면 정리

  • 설정에서 켜고 끌 수 있는 Liquid Glass(액체 굴절) 효과를 추가했습니다.
  • 프롬프트 패널과 제어 UI의 여백을 정리해 메인 화면을 더 넓게 사용할 수 있습니다.
  • Seed 옵션과 자동 생성 버튼을 고급 설정으로 통합했습니다.
  • 패널의 투명도, 테두리, 모서리 표현을 정리해 화면 전반의 일관성을 높였습니다.

[업데이트 방법]

앱을 실행하면 업데이트 안내가 표시됩니다. 업데이트를 누르면 1.5.1을 설치할 수 있습니다. 안내가 바로 보이지 않는 경우에는 앱을 다시 실행하거나 잠시 뒤 다시 확인해 주세요.

로그인 화면의 Persistent Token 발급 방법 보기를 누르면 앱 안에서도 발급 절차와 주의사항을 확인할 수 있습니다.
